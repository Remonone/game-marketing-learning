# Projects

Apply marketing knowledge to real game concepts or games here.

Each project folder may eventually contain:

- market context;
- audience hypotheses;
- comparables;
- player fantasy and product appeal;
- positioning and pitch iterations;
- validation plans and results;
- store/launch work when the project reaches that stage.

Do not force later-stage artifacts onto an early concept. Create only what is useful at the project's current maturity.
