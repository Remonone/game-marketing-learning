# Experiments

Validation work belongs here.

Every experiment should define the hypothesis before collecting evidence.

Recommended structure:

1. **Question** — what uncertainty are we trying to reduce?
2. **Hypothesis** — what do we currently believe?
3. **Target audience** — whose reaction matters for this test?
4. **Method** — what is the cheapest test that can produce useful evidence?
5. **Success / failure signals** — defined before seeing results.
6. **Evidence** — observations, responses, behavior, measurements.
7. **Interpretation** — what the evidence does and does not support.
8. **Decision** — keep, change, kill, or run another test.

Avoid treating compliments as strong validation. Prefer behavior and concrete actions when possible.
