# Exercises

Short, focused assignments for practicing one marketing skill at a time.

Prefer exercises that force a decision or argument, for example:

- choose and justify five comparables;
- define an audience from behavioral evidence;
- rewrite a weak game concept into a clear one-line pitch;
- identify competing positioning hypotheses;
- design the cheapest useful validation test.

Keep the original attempt when useful so later reviews can show how the reasoning improved.
